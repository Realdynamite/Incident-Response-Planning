# GRC205 Incident Response Planning Assignment

## Overview

This repository contains my GRC205 Incident Response Planning Assignment. The assignment focuses on incident response planning, cybersecurity incident handling, business continuity, and recovery following a security incident.

## Assignment Contents

The assignment covers the following areas:

1. **Incident Classification and Analysis** — Identifying incident indicators, assessing severity, and considering the potential impact on confidentiality, integrity, and availability.
2. **Incident Response Plan** — Defining response responsibilities, incident response stages, escalation procedures, and business continuity considerations.
3. **Incident Handling and Recovery** — Establishing response priorities, containment actions, evidence preservation, recovery objectives, and closure activities.
4. **Incident Communication** — Planning stakeholder communications, executive briefings, learner notifications, and privacy considerations.
5. **Tabletop Exercise** — Using simulated incident scenarios to evaluate decisions, response coordination, and opportunities for improvement.
6. **Case Study Reflection** — Reviewing lessons from a healthcare ransomware incident and identifying improvements relevant to the institute.

## Purpose

The purpose of this assignment is to demonstrate how structured incident response planning can help an organisation manage cybersecurity incidents, reduce disruption, preserve evidence, and restore services safely.
